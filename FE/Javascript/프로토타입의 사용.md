## 프로토타입 체인

- 특정 객체에 호출된 프로퍼티가 없다면 프로토타입을 거슬러 올라감

### Object.getPrototypeof

```javascript
function person(name){
    this.name = name;
}

console.log(person.prototype);
```

### 인스턴스 vs 프로토타임 프로퍼티

```javascript
function YalcoChicken (name, no) {
  this.name = name;
  this.no = no;
  this.introduce = function () {
    return `안녕하세요, ${this.no}호 ${this.name}점입니다!`;
  }
}

const chain1 = new YalcoChicken('판교', 3);
```

```javascript
YalcoChicken.prototype.introEng = function () {
  return `Welcome to Yalco Chicken at ${this.name}!`;
};
```

- introduce는 만들어지는 메모리마다 존재하고, `introEng` 의 경우 프로토 타입에만 존재하기 때문에 메모리가 절약된다.

## 프로토타입과 상속
```javascript
function Bird (name, sound) {
  this.name = name;
  this.sound = sound;
}
Bird.prototype.fly = function () {
  console.log(`${this.name} ${this.sound} 비행중`);
}

function Eagle (name, sound, prey) {
  this.name = name;
  this.sound = sound;
  this.prey = prey;
}
Eagle.prototype.hunt = function () {
  console.log(`${this.name} ${this.prey} 사냥중`);
}

const bird = new Bird('새돌이', '파닥파닥');
const eagle = new Eagle('독돌이', '푸드덕', '토끼');

console.log(bird);
console.log(eagle);
```

### 프로토타입으로 상속하기 Object.create메서드

```javascript
상속을 먼저 받은 다음 자신의 프로토타입을 작성한다
Eagle.prototype = Object.create(Bird.prototype);

Eagle.prototype.hunt = function(){
    console.log(`${this.name} ${this.prey} 사냥중`)
}
```

### 부모의 생성자 활용하기
```javascript
function Bird(name, sound){
    this.name = name;
    this.sound = sound;
}

Bird.prototype.fly = function(){
    console.log('bird prototype fly')
}

function Eagle(name, sound, prey){
    Bird.call(this, name, sound);

    this.prey = prey;
}

Eagle.prototype = Object.create(Bird.prototype);

Eagle.prototype.hunt = function(){
    console.log()
}
```
Bird.call() 은 Bird생성자를 호출합니다. 첫번째 인자 this는 Bird함수 내부에서 사용될 this값을 지정합니다. 여기서는Eagle생성자 내부에서 호출되므로, this는 현재 생성중인 Eagle객체를 가리킵니다. 나머지 인자들 (name, sound)은 Bird함수에 전달됩니다. 
- 이는 JavaScript에서 클래스 상속을 구현하는 전통적인 방법 중 하나입니다. ES6의 class와 extends 키워드가 도입되기 전에 주로 사용되던 패턴입니다.

### 클래스로 구현
```javascript
class Bird{
    constructor(name, sound){
        this.name = name;
        this.sound = sound;
    }

    fly(){
        console.log()
    }
}

class Eagle extends Bird{
    constructor(name, sound, prey){
        super(name, sound);
        this.prey = prey;
    }
    hunt(){
        console.log()
    }
}
```
